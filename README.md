# Hi, I'm Ankit Solanki

Computer science student and founder of **Membdel**, based in India.

## What I work on

**Membdel: LLM memorization audits and machine unlearning.**
I build tools that measure what a language model has memorized from its training data, and that test
whether "unlearning" really removes data or only hides it, so that a short fine-tune doesn't bring it back.
- Evaluation with TOFU, MUSE and WMDP through OpenUnlearning, from 1B up to 14B-parameter models
- Membership inference and extraction tests, relearning attacks, held-out retention checks
- Product code is private while in development. An open-source unlearning-audit benchmark is in progress

**Docvail: AI-assisted doctor discovery and booking** ([repo](https://github.com/as3121945-hash/Docvail) · [live](https://docvail-26827.web.app))
Patients describe symptoms in English, Hindi or Hinglish. Gemini maps them to a specialty and city, and
the app books a slot with a matching doctor. Built for the Google Solution Challenge 2026.
